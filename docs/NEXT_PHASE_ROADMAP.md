# GoreeCloud Feed Next Phase Roadmap

## Goal

Continue evolving GoreeCloud Feed from the Stable web baseline toward a complete multi-platform RSS experience.

## Priority Improvements

### Reading Experience

- richer article reader mode
- improved offline reading support
- better keyboard navigation
- reading progress and state continuity
- expanded Glaze UI polish

### Feed Management

- improved subscription organization
- bulk feed actions
- import/export workflows
- stronger FreshRSS synchronization visibility

### Native Targets

- complete Linux desktop acceptance
- complete Android acceptance
- platform-specific secure credential storage review
- release packaging and upgrade validation

### Quality Gates

- accessibility testing
- performance testing
- physical device validation
- security review

This roadmap tracks intended improvements and does not represent completed features until repository evidence exists.
